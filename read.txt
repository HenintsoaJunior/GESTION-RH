## 🚀 Intégration complète du **backend** et du **frontend** pour la fonctionnalité **Direction**

### 🎯 Objectif

Finaliser l’intégration du module **Direction** en ajoutant :

* la **pagination**
* un **filtre par nom**
* et le **CRUD complet** dans le frontend React.

Ce module doit suivre la même architecture et logique que celle déjà utilisée pour **Mission** (`MissionRepository`, `MissionService`, `mission-list.tsx`, etc.).

## 🔧 BACKEND (.NET)

**Structure concernée :**

* `Controllers/DirectionController.cs`
* `Services/DirectionService.cs`
* `Repositories/DirectionRepository.cs`
* `Entities/Direction.cs`

### 🧩 À faire :

1. **Ajouter une méthode de recherche avec pagination et filtre par nom.**

   * Inspire-toi de la logique utilisée dans :

     * `MissionRepository` → méthode `Search`
     * `MissionService` → méthode `Search`
   * La méthode doit permettre :

     * de filtrer les Directions par **nom** (`Name`),
     * et de paginer les résultats (ex. : `page`, `pageSize`).

2. **Modifier le contrôleur (`DirectionController`)** :

   * Ajouter une route `GET /api/directions/search`
   * Les paramètres acceptés :

     ```csharp
     [FromQuery] string? name, [FromQuery] int page = 1, [FromQuery] int pageSize = 10
     ```
   * Retourner un objet paginé contenant :

     ```json
     {
       "data": [ ... ],
       "totalCount": 100,
       "page": 1,
       "pageSize": 10
     }
     ```

### 🧩 Étapes d’implémentation :

#### 1. API (dans `src/api/direction`)
