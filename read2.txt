### 🧩 Objectif

Je veux que tu **t’inspires de l’intégration de la fonctionnalité *Direction*** (backend .NET + frontend React) pour implémenter la **fonctionnalité *Département*** avec recherche et liaison à la direction.

---

### 🔧 Backend (.NET)

1. **Créer une fonction `Search`** dans le dossier Controller/direction:

   * `DepartmentRepository.cs`
   * `DepartmentService.cs`
   * `DepartmentController.cs`

   Cette fonction doit permettre de **filtrer les départements par nom** (ou tout autre critère pertinent).

2. **Ajouter une méthode `GetAll`** dans le contrôleur ou le service de **Direction** afin de **récupérer toutes les directions**, pour les utiliser dans le frontend (auto-complétion).

---

### ⚛️ Frontend (React)

1. **Créer un hook CRUD** dans le dossier `src/api/departement/`, en prenant **exemple sur le hook de `direction`**.
   Le hook doit gérer :

   * `getAllDepartements`
   * `createDepartement`
   * `updateDepartement`
   * `deleteDepartement`
   * `searchDepartement`

2. Dans le dossier `src/pages/referentiel/`, créer un **dossier `departement/`** pour la gestion du module (composants, pages, etc.).

3. Dans le formulaire ou la liste des départements :

   * Ajouter un champ **Direction** lié via un **auto-complete input** (composant `AutoCompleteInput`).
   * Ce champ doit utiliser la méthode `getAll` des directions pour récupérer les suggestions.

---

➡️ Prends **Direction** comme modèle complet d’intégration.
➡️ Implémente **search + CRUD + filtre + autocomplete** pour **Département**, en respectant la structure existante du projet.
